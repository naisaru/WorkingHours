# WorkCalendar

Пиксельный календарь работы для Android: графики 1/2, 2/2, 5/2 и свободный, часы, заметки, подработки, отпуск, статистика, доход и виджет на главный экран.

APK собирается автоматически GitHub Actions при каждом push в `main`.
Готовый файл: вкладка **Releases** → `WorkCalendar.apk`.

Шрифт Press Start 2P (CodeMan38) распространяется по лицензии SIL Open Font License и скачивается во время сборки.
